这是一个假装停在 1998 年、行为却像今天部署上去的个人主页。
它存在的意义只有一个：证明老网不是"怀旧"，而是**快**。

## 制作说明 {#colophon}

| 层 | 选择 | 原因 |
| --- | --- | --- |
| 内容 | Markdown + front matter | 归 git 管，随时可搬走 |
| 渲染 | markdown-it + highlight.js | 快、可扩展、不依赖前端框架 |
| 服务端 | Node + Express | 一个进程一条命令，不要容器 |
| 存储 | 一个 SQLite 文件 | 文章、设置、留言、计数都在里面，备份就是拷这一个文件 |
| 搜索 | 内存倒排索引 | 支持中文分词，零依赖 |
| 声音 | Web Audio 方波 | 0 字节音频资源 |
| 追踪 | 没有 | 只留一个匿名访客 cookie |

## 特色功能

- **时间机器**：一键切到 1998 排版（Times New Roman、居中排版、藏青桌面），`?theme=1998` 也能分享
- **DOS 终端**：每个页面按 <kbd>Ctrl</kbd>+<kbd>K</kbd>
- **芯片音乐**：浏览器现场合成，不自动播放
- **访问计数器**：总数、今日、独立访客、在线人数
- **环形网**：上一站 / 下一站 / 随机
- **留言板**：审核队列 + 蜜罐反垃圾
- **.TXT 下载**：每篇文章都有纯文本版
- **中英切换**：右上角切换，`?lang=en` 也可以分享
- **自定义后台路径**：在配置文件里改成任何你记得住的地址

## 装一个自己的

```bash
git clone https://github.com/you/oldie-blog
cd oldie-blog
nvm use            # 建议 Node 24
pnpm install
pnpm start         # → http://localhost:4173
```

然后访问 `/admin` 登录。第一次启动会在终端里打印一个临时密码，进去之后在后台写第一篇。

已经有写好的 `.md`？放进 `content/posts/`，跑一次 `pnpm start` —— 首次启动会把它们导进
数据库，导完这些文件就可以删了。

## 多语言

界面默认中文，右上角可以切到英文。
语言选择记在一个 cookie 里，搜索引擎也会通过 `hreflang` 知道两个版本。
想加第三种语言？在 `src/lib/i18n.js` 里再加一个字典就够了，
其他任何文件都不需要改。
